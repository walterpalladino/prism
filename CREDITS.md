  include any PICO-8 code or assets. PICO-8 is a trademark of Lexaloffle Games.
- The sprite sheet JSON follows the publicly documented Aseprite sprite sheet layout for compatibility;
  no Aseprite code is used. Aseprite is a trademark of Igara Studio S.A.
- Deluxe Paint (DPaint) is a trademark of Electronic Arts. PRISM reimplements behavior described in
  public manuals; no DPaint code is used.
- The GIF encoder uses LZW compression; the related patents expired in 2003–2004.
- Names are used only to describe compatibility and inspiration; PRISM is not affiliated with or endorsed
  by these companies.
